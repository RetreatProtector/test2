Команда Что делает cd *название папки* - перейти в папку git init Инициализировать репозиторий git add . Добавить файлы для следующего коммита пишем либо точку - добавить все файлы, либо конкретный файл пиши git commit -m Зафиксировать изменения -m это ветка git push -u origin main Отправить коммиты в репозиторий git pull — это команда, которая стягивает изменения с удалённого репозитория (например, GitHub) и сразу применяет их к твоей текущей локальной ветке. git branch *название ветки* - создание новой ветки git checkout -- . - откат изменений (в случае с точкой всех файлов. если нужно конкрутного - указывай название)
